Save online and use on every device

Your rents, sales and deal figures are saved to a private file in your own GitHub account. Every change uploads automatically, and each device downloads the latest when you open the app. Do this once on each device:

  1. Open GitHub → new access key ↗ (sign in if asked).
  2. Set Expiration to No expiration or a year. Leave only the gist box ticked.
  3. Press Generate token, copy the key that starts with ghp_, and paste it here.

The key stays on this device and can only read and write your gists, not your code. You can use the same key on every device.

This device is connected. Changes save online a couple of seconds after you make them, and the latest data loads when you open the app.
